# FusionPlay Windows · 测试版

Windows 10 22H2 / Windows 11 x64 原生 MiPlay 音乐接收器。界面使用 C# / WinUI 3，协议与音频使用共享 Rust 核心。首版只接收小米妙播。

## 使用

1. 将完整 ZIP 解压到可写目录，双击 FusionPlay.Windows.exe。不要只复制 EXE。
2. 打开后自动开始接收。手机、电脑、音箱连接同一局域网，在手机妙播中选择 FusionPlay-Windows。
3. 全屋播放在手机中添加音箱和此电脑。关闭播放窗口后仍在托盘运行；托盘“退出”才停止整个应用。

托盘左键打开接收面板，右键提供显示窗口、设置、接收启停与退出。播放窗口与托盘共享音量和控制状态。

## 播放器与设置（0.2.0）

播放窗口按尺寸自适应：宽度达到 600 且高度达到 360 时使用大布局，可自由调整长宽；缩小到任一阈值以下时切换为封面小布局，并保持 1:1。默认 420 × 420，最小 260 × 260。关闭按钮仅在鼠标位于窗口内时显示，移出淡出；设置和全屏按钮可分别在播放器设置中隐藏，迷你窗口不显示设置按钮。拖动封面空白处移动窗口。小布局悬浮时先舒缓淡入背景模糊，再以重叠时序淡入歌曲信息和控件，移出则以相反顺序淡出。系统关闭动画或启用高对比度时减少相应视觉效果。

迷你播放器内不显示设置按钮。单击托盘白色双环图标打开亚克力背景的曲目面板，扬声器图标旁的滑条调节音量。面板中的设置按钮或 Ctrl+, 可打开设置，电源按钮退出应用；右键仍可显示快捷菜单。面板封面和歌名可唤出播放器。应用图标采用圆角矩形，托盘状态图标采用透明底白色加粗轮廓。

设置使用原生侧栏，分为接收、音频、播放器、通用和关于。Ctrl+, 打开设置；接收页管理名称、实际网卡与 IP 和接收启停，音频页选择实际声音设备及调整同步。两页分别“应用并重新连接”，只提交本组修改。播放器页以紧凑卡片分别选择播放控制、进度与时间、置顶按钮；少量互斥选项使用分段选择。通用页管理语言、字体和任务栏 / 托盘入口。界面偏好即时生效并自动保存。

设置顶栏融入窗口内容，保留 Windows 原生拖动、缩放及窗口按钮。自定义字体与所选字重覆盖各设置页、播放器和托盘；标题保留一致的层级，系统图标与诊断等宽字体保持各自用途。开启或关闭歌词不会改变歌名、歌手的字号。歌词展开布局按窗口比例分配左右留白、列宽及间距；左侧封面、歌曲信息与控件整体垂直居中，封面保持正方形并受可用高度约束，右侧歌词独立滚动。

设置页面切换与侧栏展开、收起加入轻量淡入过渡，保留当前页面实例、字体选择与尚未应用的草稿。侧栏和客户端顶栏使用连续的 Windows Mica 背景，系统不支持或启用高对比度时回退纯色；原生导航按钮和窗口输入方式保持原样。

进度条颜色可选跟随系统主题、始终白色或自定义颜色，大小播放器同步生效；只在自定义时显示选色器。隐藏进度时保留已有颜色。封面切换保留前一张图片直到替换完成；持续缺失封面、加载失败或断开时清除，系统媒体卡片不会沿用旧曲目的封面。

任务栏和托盘入口可分别显示或隐藏，默认都开启。关闭播放窗口后若托盘隐藏，会打开设置以便恢复入口。两项均隐藏时，重新双击程序也可进入设置。隐藏入口不会停止音乐接收。托盘图标区分待机、播放和暂停，面板提供封面、曲目信息、细音量条及播放控制。

播放、暂停和切歌发给手机；正常发送及确认不显示额外提示，不会因未确认而重复切歌，失败时才提示。播放按钮开关使用淡入淡出和高度收放动画。托盘面板中的封面随右侧歌曲信息和控件的实际高度调整，文字与播放图标共用左边线；底栏扬声器可展开和收起细音量条，支持点击、拖动和键盘调节。大小播放器的进度条支持点击跳转，点击后立即显示待确认位置，再与手机实际回报校准；失败或 5 秒未收到对应位置时回退到真实进度。播放器设置中的“进度与时间”可同时隐藏进度条和时间文字，并保留已选颜色；显隐时淡入淡出并平滑收放高度，开始隐藏时立即停用跳转，快速切换可反向过渡。未提供时长/位置、已断开或切歌期间不发送过期跳转。

实际播放后接入 Windows 系统媒体卡片和媒体键，发布手机提供的曲目、歌手、专辑、封面及进度。应用启动时登记本用户的应用名称与图标，以便系统识别 FusionPlay；不添加开机启动项。停止、断开和退出时清理本应用媒体信息；多个音乐应用同时运行时，媒体键目标由 Windows 决定。

播放器的进度填充固定在左侧起点，前进、回退和重复位置回报只更新填充长度，避免回退时整段位移后弹回。进度条与时间组的显隐过渡独立保留。

歌曲界面中的进度区只按显示偏好展开或收起。切歌信息分批到达、暂时缺少时长或位置时，保留同一位置和高度；未知时间显示“--:--”，不能计算的填充归零，并立即禁用跳转、取消旧手势。播放按钮及音量也保留布局，接收状态只决定是否可操作。

没有当前歌曲时进入简洁待机界面：只保留原生 Acrylic 背景、音符和窗口管理按钮，不显示歌曲信息、进度和播放控制，也不改写显示偏好。收到歌曲后按原设置恢复；切歌时短暂缺少时间或控制状态不会被当成无歌曲。系统高对比度或材质不可用时使用纯色回退。

“设置 → 播放器 → 修正歌词标题”默认关闭。开启后，仅在收到的歌词头信息、可信组合字段和歌词片段能够相互核对时，恢复被歌词句替代的歌名。播放器、托盘和 Windows 系统媒体信息使用相同展示结果，暂停时切换选项也会更新；原始快照、曲目标识、进度和播放控制请求保持不变。不会联网搜歌、保存歌词或增加歌曲日志；缺少可核对信息时保留原样。

## 歌词、显示模式与全屏（0.2.0-preview18）

设置 → 播放器 → 显示歌词提供“自动 / 始终关闭”。自动模式在解析到有效歌词后提供歌词区和歌词入口，布局按窗口尺寸与外观偏好调整。异步替换期间保留原布局，前奏、间奏和暂停不隐藏已有歌词。始终关闭会在所有布局中关闭歌词和入口。旧版“始终开启”会按“自动”读取，其余偏好保留。

上一曲已有歌词而新曲首批信息暂未带歌词时，先清除旧歌词与位置，在原布局等待最多 2 秒。同曲重复信息不会延长等待；新词到达后正常显示，确实无词才在等待结束后自动收起，断开则立即清理。首曲没有歌词时不会额外打开歌词布局。

播放器设置中的“歌词背景”可选“专辑模糊”或“亚克力”，默认为“专辑模糊”。迷你窗口的背景应用于封面下方的歌词区，展开布局和全屏也使用所选材质。系统材质不可用时显示纯色背景。

歌词界面参考 Mac 歌词分支：小窗口上方封面保持与窗口同宽的正方形，下方歌词至少预留 128 DIP，保留 8 DIP 透明间隔，不额外绘制分隔线。整个窗口可以独立调整长宽，关闭歌词的小窗口恢复 1:1。本次运行内会记住用户调整过的歌词区高度，关闭、切歌或经过无歌词阶段后再次显示时恢复；封面宽度改变时保留歌词区高度，并按当前屏幕工作区裁切。全屏不会覆盖这一记忆。显示歌词且宽度达到 600 DIP 时使用左侧封面和控制、右侧歌词的大布局，也支持宽而矮的窗口。歌词开关时封面和歌曲信息保持可见并平滑移动、缩放，歌词区域单独淡入淡出，迷你窗口高度同时舒缓收展；跨越大小布局时交叠显示，快速反向切换以最后一次请求为准。歌词因横向拉伸换行时，新旧字形短暂交叠淡入淡出，邻行位置同步过渡。歌词当前句位于阅读区约上三分之一，原文突出、翻译显示在下方，上下边缘逐渐模糊和淡出；系统高对比度或关闭透明效果时减少相应视觉效果。

带时间戳的 LRC 跟随手机位置和待确认跳转，点击歌词行可请求手机跳转。手动滚动及惯性停止约 5 秒后自动恢复跟随，持续按住或滚动时不抢回，不显示额外的返回按钮；屏幕阅读器启用时不自动拉动阅读位置。纯文本歌词自然滚动，不编造时间。歌词和翻译只在内存中使用，不写入缓存或歌曲日志，不额外联网搜词；输入最多 256 KiB，显示最多 4000 行。手机没有发送歌词时无法补出歌词。

带时间戳的空歌词行表示歌词间隔，以小号、固定一行的省略号显示；不会把三个点拆成两行，原时间点及跳转行为保留。

播放器提供全屏按钮、右键菜单和托盘全屏入口，也可按 F11 或 Ctrl+Shift+F 切换，Esc 退出。使用 Windows 原生全屏模式，进入时释放方形约束并暂时取消置顶，退出后恢复原窗口位置、尺寸和置顶偏好。切换期间保留背景缓存，封面和文字从原屏幕位置衔接到新布局，避免先清空背景再重新加载；过渡期间暂停跳转，结束或取消后恢复。全屏与歌词显示模式分别控制，播放暂停不改变窗口策略。

## 连接与声音

自动选择优先采用有网关的物理 Wi-Fi / Ethernet。必要时在设置中手动选择网卡，保存后在手机上重新选择设备。应用不会修改代理或 VPN 设置。

声音输出默认跟随系统，也可固定设备。若电脑默认输出为没有扬声器的显示器，请在应用中选择实际扬声器。固定设备断开时提示错误，不静默切换到其他设备。

网络及默认输出改变时受控重连，失败最多重试三次。睡眠停止接收，唤醒后只恢复用户此前请求的接收状态。

如果 Windows 提示访问网络，请允许专用网络。设置中的“允许局域网连接”可为当前程序路径添加仅限专用网络、本地子网的入站规则；这一步请求管理员权限，应用本身不需要管理员权限。移动程序后可能需要重新配置路径规则。

不安装登录启动项；运行所需组件随包提供。

## 便携数据与升级

程序旁的 FusionPlayData 保存设置、设备身份与轮换日志。升级时退出应用，替换程序文件并保留这个目录。

同一电脑内移动整个目录保留身份。复制到其他电脑/用户时，本机保护的归属标记可能无法读取；应用要求明确选择“为此电脑建立独立身份”，保留通用设置并备份旧身份，不重置手机数据。

目录不可写时显示错误，不暗中切换数据目录或生成另一身份。封面只在内存加载，支持 HTTP/HTTPS、Data URL 和无前缀 Base64，最大 4 MB。日志不记录认证材料、原始网络包、曲目或封面内容。

## 构建

需要 PowerShell 7、Visual Studio C++ Build Tools（MSVC x64）和 Windows SDK。准备脚本将 .NET 10.0.403、Rust MSVC 和缓存放在项目专用目录，不修改系统 PATH；可用 FUSIONPLAY_WINDOWS_TOOLS 指定工具目录。

~~~powershell
./windows/scripts/setup-tools.ps1
./windows/scripts/build.ps1
./windows/scripts/test.ps1
# 应用关闭后额外执行本机真实网络启停检查
./windows/scripts/test.ps1 -Network
./windows/scripts/package.ps1
~~~

真实默认音频端点的静音渲染检查：

~~~powershell
. ./windows/scripts/env.ps1
cargo test --locked --manifest-path ./src/FusionPlay.MiPlaySdk/Cargo.toml --lib silent_native_endpoint_renders_and_pauses -- --ignored
~~~

Windows 原生工程位于 windows/FusionPlay.Windows，便携数据与 C ABI 封装位于 windows/FusionPlay.Core，集成测试位于 windows/FusionPlay.Tests。Mac UniFFI 和 Android JNI 保持各自现有接口。

## 验收边界

测试版。自动化测试、静音端点渲染及内部调度误差不能替代手机实播和声学同步验收。

全屋同步目标为 20 ms，需要同次录音中的瞬态信号，控制麦克风距离差，覆盖至少 30 分钟的初期、中段和末段。蓝牙不纳入首版同步验收；没有实测数据时不标记达标。详见源码中的 windows/VALIDATION.md。

音频页提供 −500～+500 ms 声音同步微调，默认 0：负数提前、正数延后。滑条两侧的 − / + 每次提前 / 延后 10 ms，也可拖动滑块、输入整数或恢复默认。调整时短暂淡出再恢复，立即生效并按声音端点保存，不需要重新连接。输出选择尚未应用时暂不能修改校准，应用后读取该设备的独立设置。旧版提前 120 ms 会自动作为 −120 ms 使用，保留原播放方向和调节幅度。提前效果受已接收音频和最低安全缓冲限制；实际是否达到 20 ms 目标仍需声学测量。

通用页展开“字体设置”，可从已安装字体中按字族选择界面字体，字重在另一个选框中选择，仅列出该字族实际可用的字重；在字体列表中键入名称可快速定位。标题保留同字族的较粗字重，图标与等宽诊断文本保持各自的字体。字体缺失时回退到系统字体并保留原选择，可一键恢复默认。

播放器文字效果可选“柔和”或“系统默认”，设置中提供即时字体预览。柔和模式通过原生 DirectWrite/Direct2D 绘制歌名、歌手和时间，并对字形边缘做轻量浓淡调整；适配当前屏幕 DPI 和系统文字缩放。高对比度或绘制失败时回退到系统文字控件，屏幕阅读器仍能读取文本。MacType 等外部工具可能接管 DirectWrite 参数，本应用不修改这些工具的配置。

界面偏好另存在 FusionPlayData/data/ui-preferences.json，包含字族、字重与文字效果；声音微调保存在 output-calibration.json。设备身份和 Windows 便携运行方式沿用原有逻辑。
